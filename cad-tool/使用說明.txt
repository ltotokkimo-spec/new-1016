簡易機械 CAD — 使用說明
========================

【開始使用】
1. 雙擊 MechCAD.exe 開啟程式（第一次開啟會整理系統字型，稍等幾秒）。
2. 可以直接把 DWG / DXF 檔拖進視窗開啟。

【DWG 開檔與存檔：ODA File Converter（免費，自動安裝，只要一次）】
1. 第一次開啟程式時會詢問「要現在自動安裝嗎？」，按「安裝」。
2. 程式會從 ODA 官方網站下載並安裝；Windows 問「是否允許變更」時按「是」。
3. 裝好後下次開啟會自動跳過。若選了「以後再說」，之後可從「說明 → 自動安裝 ODA File Converter」安裝。
   自動安裝失敗時（例如沒有網路），可手動到 https://www.opendesign.com/guestfiles/oda_file_converter
   下載 Windows 64-bit 版本安裝。
※ 沒裝 ODA 也能「開啟」DWG（用內建的 LibreDWG），但無法「存成」DWG，只能存 DXF。

【基本操作】
- 滾輪：縮放　按住滾輪（中鍵）拖曳：平移　雙擊中鍵：看全部
- 下方指令列輸入指令後按 Enter 或空白鍵；滑鼠右鍵 = Enter；Esc = 取消
- 直接按 Enter = 重複上一個指令
- 由左往右框選 = 完全框住才選；由右往左 = 碰到就選；Shift+點 = 取消選取
- F3 物件鎖點（端點、中點、圓心、交點…）　F8 正交

【座標輸入】
  100,50     絕對座標
  @30,0      相對上一點
  @50<30     距離 50、角度 30 度
  25         沿著滑鼠方向 25

【常用指令】（完整列表按 F1）
  繪圖：L 直線  PL 聚合線  REC 矩形  C 圓  A 圓弧  POL 多邊形  T 文字
  修改：M 移動  CO 複製  RO 旋轉  MI 鏡射  SC 縮放  O 偏移
        TR 修剪  EX 延伸  F 圓角  CHA 倒角  X 分解  E 刪除
  標註：DLI 線性  DAL 對齊  DRA 半徑  DDI 直徑  DAN 角度  LE 引線
        標註時可輸入 D 加 Ø、P 加公差（例 +0.02/-0.01）、F 加配合（例 H7）
  機械：CM 中心線  H 剖面線  FRAME 圖框（CNS / ISO，A0–A4）
  查詢：DI 量距離  LI 物件資訊
  特殊符號：%%c = Ø　%%p = ±　%%d = °

【CNS 和 ISO 的差別】
  兩者的線型、字高、箭頭大致相同；
  CNS（台灣）用第三角法、中文標題欄；ISO（歐洲）用第一角法、英文標題欄。
  新建圖面時可選（檔案 → 新建 CNS / ISO 圖面）。
