# 股市雷達（Android 選股 App）

個人用的台股／美股選股工具：找出近期有動能、族群輪動、外資買進的股票，給出「買入／觀望／離場」評等；可以拍證券 App 的庫存截圖匯入持股，並用 Claude 搜尋最新新聞與國內外經濟數據寫成解析。

## 安裝
1. 用 Android 手機打開 GitHub 的 Releases 頁面「股市雷達（最新版）」，點 `stock-radar.apk` 下載。
2. 第一次安裝時，手機會要求允許「安裝不明來源的應用程式」，允許瀏覽器安裝即可。
3. 之後每次更新都直接下載新版覆蓋安裝，持股資料會保留。

## 功能
| 分頁 | 內容 |
|---|---|
| 選股 | 台股（上市＋上櫃）／美股大型股，依分數排序，可篩選買入／觀望／離場、搜尋代號 |
| 族群 | 各產業近 1 週／1 月中位數報酬、外資 5 日買賣超金額、上漲家數比，標示「轉強／強勢延續／轉弱／弱勢」 |
| 持股 | 拍照或截圖匯入（Claude 辨識）、手動新增；顯示現價、損益、評等與建議，虧損達 10% 提醒停損 |
| 數據 | 台股指數、美股指數、美債殖利率、美元指數、匯率、原油、黃金；Claude 解讀最近一週國內外數據發表 |
| 設定 | 貼上 Claude API 金鑰、更新或清除資料 |

## 評分規則（App 內每檔股票都會列出理由）
- **台股分數** = 動能 40%（近 1 週／1 月／3 月漲幅在全市場的排名）＋ 外資籌碼 40%（外資 5 日買超佔成交比重、連續買超天數、投信）＋ 族群強弱 20%
- **美股分數** = 動能 40% ＋ 趨勢 40%（50 日均線、20/50 日均線排列、相對 S&P 500）＋ 產業強弱 20%
- **買入**：分數 ≥ 70、外資買超（美股：站上 50 日均線）、近 1 週漲幅未超過 20%
- **離場**：分數 < 40，或近 1 月跌逾 10% 且外資賣超（美股：跌破均線）
- 其餘為 **觀望**。只評分當日成交金額 5 千萬台幣（美股 2 千萬美元）以上的股票。

## 資料來源
臺灣證券交易所、證券櫃檯買賣中心（每日行情、三大法人、產業別）、Nasdaq（美股日 K）、CNBC（國際指標）。證交所約下午 3~5 點公布當日法人資料；已下載的交易日會存在手機裡，之後只補新的一天。

## Claude AI
- 金鑰到 console.anthropic.com 建立，只存在手機裡、直接呼叫 Anthropic。
- 使用模型 `claude-opus-5-5`，開啟網路搜尋；若 Claude 因安全規則拒答會自動改用備援模型（server-side fallback）。
- 個股解析約台幣 3~8 元／次，每日數據解讀約 5~10 元／次（依搜尋次數與長度而定）。

## 開發
```bash
npm ci
npx vitest run            # 單元測試（解析器與評分用真實回應樣本）
npm run dev               # 瀏覽器開發；網路會經過 /proxy 轉發
FIXTURE_DIR=<資料夾> npm run dev   # 用存下來的真實回應開發（連不到交易所時）
npm run build && npx cap sync android && (cd android && ./gradlew assembleDebug)
```
GitHub Actions（`.github/workflows/stock-app.yml`）會打包 APK、在 Android 模擬器上用真實網路資料實測（`tools/e2e-android.cjs`），通過後發布到 Releases。若在 repo 的 Secrets 設定 `ANTHROPIC_API_KEY`，會一併實測照片辨識與 AI 解析。

> 本 App 為個人研究工具，評等依公開數據以固定規則計算，AI 解析可能有誤，不構成投資建議。
